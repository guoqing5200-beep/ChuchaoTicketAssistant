# 楚超抢票助手（基础版）

适用于 Android 6.0 及以上设备，目标设备为小米 MIX Fold 一代 / Android 13。

## 当前版本功能
- 打开猫眼移动网页入口（https://m.maoyan.com/）
- 在应用内浏览购票页面
- 展示预设购票目标：3 张、不限票档

## 重要说明
这是一个基础入口/浏览辅助应用，不会绕过猫眼的排队、验证码、风控或支付流程，也不承诺自动抢票或保证购票成功。请遵守平台规则，并由本人确认订单和付款。

## 云端编译
仓库包含 GitHub Actions 工作流。上传源码后，可在 GitHub 的 Actions 页面运行 `Build Android APK`，下载 `ChuchaoTicketAssistant-debug-apk` artifact。APK 文件名为 `app-debug.apk`。
